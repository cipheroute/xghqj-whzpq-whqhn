# Сети (ASN) крупных российских компаний для тега DIRECT в geoip-mini.dat.
# Читают tools/fetch-geoip-sources.sh и tools/build-geoip.mjs.
#
# Российские сервисы через VPN не идут никогда: в DIRECT попадают все IPv4-префиксы,
# которые эти ASN анонсируют, даже если часть сетей стоит за границей.
#
# Строка: AS<номер>  # компания, что это. Всё после # — комментарий.
# Адреса — анонсируемые IPv4-префиксы по RIPEstat (announced-prefixes, окно две недели);
# IPv6 не берём. Если RIPEstat по ASN не ответил, сборка берёт его префиксы из
# direct-asn-cache.txt и пишет об этом в отчёте.
#
# Номер добавлять, только если держатель по RIPEstat as-overview
# (https://stat.ripe.net/data/as-overview/data.json?resource=AS<номер>) — та самая компания.
# Все номера ниже сверены так 05-11-2026; держатель записывается в кэш, и при его смене
# отчёт сборки выдаёт предупреждение.
#
# Не включены (05-11-2026):
#   - региональные ASN операторов (у Ростелекома их 122, у МТС 96, у МегаФона 40,
#     у Билайна 36): все их анонсы и так в geoip:ru, сверх него — ни одного адреса;
#   - Yandex Cloud в Казахстане (AS208795, AS219109): держатель «Cloud Services Kazakhstan» LLP,
#     облако для сторонних клиентов в Казахстане;
#   - Cloud.ru (AS208677, бывший SberCloud): держатель «Cloud Technologies» LLC, облако для
#     сторонних клиентов;
#   - AS209517 (JSC «TCS»): по названию не ясно, что это Т-Банк;
#   - номера без анонсов (AS215109, AS213952, AS211963, AS199295, AS33844, AS35013 и др.).
